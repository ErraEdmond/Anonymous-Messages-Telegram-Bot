# Anonymous-Messages-Telegram-Bot

This is a simple asynchronous Telegram bot that can be used for both receiving and sending messages. 

## Features. 

1. Anonymous messages 
2. Signed messages. 
3. Integrated database. 

# How to install. 

1. Install all required libraries from *requirements.txt*.
2. Fill out *config.py* and write in the Telegram bot's token into TOKEN and your Telegram ID in ADMIN to get access to the admin panel. 
3. Run *main.py*.
